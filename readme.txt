kotori-os
=========

After a long while of programming exactly nothing,
I've wanted to return to kotori-os. In spite of all
the issues, it still proved to be my most fun project
and I intend to try again to write this. 

I'm starting from scratch, because my old (not like the
5 that came before that) kotori-os source code was built
around the Limine bootloader and the GNU compiler. Both 
proved to make things only more difficult than needed;
it is more time-consuming that way, but if something 
doesn't work, I want it to be a mistake on my behalf and
not some obscure feature of some third-party software I'm
using that isn't documented anywhere and just causes 
trouble. Overall, I think it was closer to what I wanted
when kotori-os was a bare metal FORTH, closer to what I
wanted it to become, so to say.

This is enough talk for now. No code has been written yet
and who the hell reads this? Anyhow...

In regards to licensing, I feel bad, because a lot of ideas
and code is plundered from tutorials, the OSdev Wiki, Stack
Exchange, and other such places. That being said, I will try
to keep this project as clean as possible and write the code
by myself mostly. It's Creative Commons Zero 1.0 -- essentially
a public domain waiver -- and as such you are free to do 
whatever you want with the source code.
